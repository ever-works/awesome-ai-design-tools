## AI Design Plugins

- [Figma Make](https://www.figma.com/) - An AI feature within Figma that generates UI designs and prototypes from text prompts. It is available to Figma users as part of the design platform. ([Read more](/details/figma-make.md)) `AI-Powered` `Freemium` `API` `Figma Plugin`

## Design-to-Code

- [Builder.io](https://www.builder.io/) - A visual development platform that connects designs to code using AI. It supports headless CMS and e-commerce integrations. ([Read more](/details/builder-io.md)) `AI-Powered` `Freemium` `API` `CMS`
- [Locofy](https://www.locofy.ai/) - A tool that converts Figma and Adobe XD designs into frontend code. It uses AI to accelerate the design-to-development process. ([Read more](/details/locofy.md)) `AI-Powered` `Freemium` `Figma` `Code Export`
- [TeleportHQ](https://teleporthq.io/) - An AI website and UI builder that exports code for developers. It supports collaboration and component reuse. ([Read more](/details/teleporthq.md)) `AI-Powered` `Freemium` `Code Export`
- [v0](https://v0.dev/) - A generative AI tool that creates React code and UI components from text prompts. It is developed by Vercel. ([Read more](/details/v0.md)) `AI-Powered` `Freemium` `React` `Code Generation`

## Graphic & Brand Design

- [Adobe Express](https://www.adobe.com/express) - An AI-powered graphic design tool for creating social media graphics, flyers, and videos. It includes templates and generative features. ([Read more](/details/adobe-express.md)) `AI-Powered` `Freemium` `Graphic Design`
- [Adobe Firefly](https://firefly.adobe.com/) - Adobe's generative AI model for creating images, vectors, and text effects. It integrates with Creative Cloud applications. ([Read more](/details/adobe-firefly.md)) `AI-Powered` `Freemium` `API` `Adobe`
- [Canva Magic Studio](https://www.canva.com/) - A suite of AI tools integrated into Canva for graphic design, image editing, and content generation. It supports teams and individuals. ([Read more](/details/canva-magic-studio.md)) `AI-Powered` `Freemium` `Graphic Design`
- [Khroma](https://khroma.co/) - An AI color palette generator that learns user preferences to create combinations. It is designed for designers seeking color inspiration. ([Read more](/details/khroma.md)) `AI-Powered` `Free` `Color Palette`
- [Microsoft Designer](https://designer.microsoft.com/) - An AI graphic design app for creating social media posts, invitations, and marketing materials. It integrates with Microsoft 365. ([Read more](/details/microsoft-designer.md)) `AI-Powered` `Freemium` `Microsoft`
- [Midjourney](https://www.midjourney.com/) - An AI image generation service accessed via Discord. It is used for creating graphics, concept art, and visual assets. ([Read more](/details/midjourney.md)) `AI-Powered` `Paid` `Image Generation`
- [Recraft](https://recraft.ai/) - An AI art generator for creating vector art, icons, and illustrations. It offers tools for professional graphic design workflows. ([Read more](/details/recraft.md)) `AI-Powered` `Freemium` `Vector Art`
- [Stable Diffusion](https://stability.ai/) - An open-source text-to-image model for generating graphics and art. It can be self-hosted or used via API. ([Read more](/details/stable-diffusion.md)) `Open Source` `Self-Hosted` `API` `Image Generation`

## Prototyping

- [Framer AI](https://www.framer.com/) - A website builder that uses AI to generate and publish sites from text prompts. It includes design and prototyping capabilities. ([Read more](/details/framer-ai.md)) `AI-Powered` `Freemium` `Website Builder`
- [Penpot](https://penpot.app/) - An open-source design and prototyping tool for teams. It supports web standards and allows self-hosting. ([Read more](/details/penpot.md)) `Open Source` `Self-Hosted` `Free Plan` `Prototyping`
- [Wix Studio](https://www.wix.com/studio) - A web design platform for agencies with AI features for layout and content generation. It includes prototyping and development tools. ([Read more](/details/wix-studio.md)) `AI-Powered` `Freemium` `Website Builder`

## UI Generation

- [Galileo AI](https://www.galileo.ai/) - An AI interface design tool that generates editable UI designs from text descriptions. It outputs designs compatible with Figma. ([Read more](/details/galileo-ai.md)) `AI-Powered` `Freemium` `Figma`
- [Google Stitch](https://stitch.google.com/) - A Google AI tool for generating user interface designs from natural language descriptions. It is currently available as a preview project. ([Read more](/details/google-stitch.md)) `AI-Powered` `Free Plan` `Google` `Free`
- [Relume](https://relume.io/) - An AI sitemap and wireframe generator for web designers. It creates copy and wireframes that can be exported to Figma or Webflow. ([Read more](/details/relume.md)) `AI-Powered` `Freemium` `Sitemap`
- [Uizard](https://uizard.io/) - An AI-powered UI design tool for creating wireframes, mockups, and prototypes. It allows users to generate designs from text or screenshots. ([Read more](/details/uizard.md)) `AI-Powered` `Freemium` `Prototyping`
- [Visily](https://visily.ai/) - An AI wireframing tool that converts screenshots or sketches into editable UI designs. It targets product managers and developers. ([Read more](/details/visily.md)) `AI-Powered` `Freemium` `Wireframing`
